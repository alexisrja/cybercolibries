# CyberColibries brand assets

Originals: `rescursos/LogoCyberColibris.png` and the supporting white-background
version `rescursos/Gemini_Generated_Image_4rb0ms4rb0ms4rb0.png`. Neither was modified.

`logo-transparent.png` is a cleaned, AI-assisted derivative produced with the
built-in imagegen tool on 2026-09-19. Its actual resolution is 1254 x 1254 pixels,
with an alpha channel. It is not a vector and does not contain 2K native detail.

Editing brief: preserve the multicolored mechanical hummingbird's identity,
pose, silhouette, feather shapes, beak, circular details, black contours and
colors; remove the background and background glow; clean compression noise
and jagged edges; preserve opaque white areas within the logo; no added text,
shadow or redesign. The requested 2048 x 2048 output was returned at 1254 x 1254.

Web derivatives:

- `logo.webp`: lossless WebP, original dimensions, used by `BrandMark`.
- `logo-512.png`: 512 x 512, used for social imagery, schema.org and the manifest.
- `icon-192.png`: 192 x 192, used by the app manifest.
- `src/app/icon.png`: 64 x 64 browser icon.
- `src/app/apple-icon.png`: 180 x 180, on white for Apple home screens.

Web and icon sizes were derived using Sharp without enlarging the master.
The site requests responsive images at quality 90 and reserves their dimensions.
The other resources are alternative brand compositions, not photographs of
community events or mentors; they are not used to illustrate those sections.
